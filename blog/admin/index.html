📝 文章发布器

填写下面的表单，自动生成需要保存的文件内容

📋 发布步骤

  1. 启动本地服务器：在当前目录运行 npm install 安装依赖，然后运行 npm start
  2. 点击「自动生成」获取下一个可用 ID（或手动输入）
  3. 填写文章信息（标题、日期、作者、标签、摘要）
  4. 在编辑器中粘贴或编写 Markdown 内容（不需要一级标题）
  5. 点击「一键发布」按钮，文件将自动写入项目目录
  6. 使用 Git 提交并推送到 GitHub

✅ 本地模式已启用 一键发布会直接写入 blog/posts/ 和 data/posts.json

📄 文章信息

使用数字 ID（如：1, 2, 3），点击「自动生成」按钮获取下一个可用 ID
多个标签用英文逗号分隔，可留空
建议 50-100 字
